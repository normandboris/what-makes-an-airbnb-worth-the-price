# What Makes an Airbnb Worth the Price?
### Predicting Nightly Listing Prices Across New York City

---

## Project Overview

This project builds and compares two regression models (Multiple Linear Regression and Random Forest) to predict the nightly price of Airbnb listings in New York City. Features include location, room type, listing size, host status, and review data. The project also includes an interactive choropleth map visualizing median prices across all NYC neighborhoods.

## Setup Instructions

### 1. Prerequisites

Make sure you have **Python 3.8+** and **Jupyter Notebook** or **JupyterLab** installed.

### 2. Install Dependencies

Run this in your terminal to install all required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn folium
```

### 3. Download the Data

The dataset is **not included** in this repository due to its size. Download it manually:

**Airbnb Listings (NYC):**
1. Go to [https://insideairbnb.com/get-the-data/](https://insideairbnb.com/get-the-data/)
2. Scroll to **New York City, New York, United States**
3. Download `listings.csv.gz` (the detailed listings file)
4. Place it in the **same folder** as the notebook

**NYC Neighborhood Boundaries (GeoJSON):**
1. Download from NYC Open Data:
   ```
   https://data.cityofnewyork.us/api/geospatial/cpf4-rkhq?method=export&type=GeoJSON
   ```
2. Save it as `neighbourhoods.geojson` in the **same folder** as the notebook

### 4. Run the Notebook

```bash
jupyter notebook airbnb_predictor.ipynb
```

Then run all cells top to bottom using **Kernel → Restart & Run All**.

> ⚠️ The Random Forest cell (`n_estimators=100`) may take 10–30 seconds to train depending on your machine.

## Data Source & Privacy

Data is sourced from [Inside Airbnb](https://insideairbnb.com), an independent, publicly available dataset. It contains no personally identifiable information — host names are already public on the Airbnb platform. The model predicts listing prices and has no potential for misuse.
