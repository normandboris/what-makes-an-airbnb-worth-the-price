# What Makes an Airbnb Worth the Price?
### Predicting Nightly Listing Prices Across New York City

---

## Project Overview

This project predicts nightly Airbnb listing prices in New York City using:

- A **naive baseline** (median price by neighborhood)
- **Ridge regression** (regularized linear model with neighborhood dummies)
- A **tuned Random Forest** regressor

The pipeline includes outlier filtering, missing-value imputation (instead of dropping ~60% of rows), dollar-scale error metrics, train-only cross-validation, residual diagnostics, and an interactive choropleth map of median prices by neighborhood.

## Setup Instructions

### 1. Prerequisites

**Python 3.8+** and **Jupyter** (Notebook or Lab).

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Download the Data

Data files are **not** in the repo (see `.gitignore`). Download manually:

**Airbnb Listings (NYC):**
1. [Inside Airbnb — Get the data](https://insideairbnb.com/get-the-data/)
2. Under **New York City**, download `listings.csv.gz`
3. Place it in the project root (same folder as the notebook)

**NYC Neighborhood Boundaries (GeoJSON):**
1. [NYC Open Data export](https://data.cityofnewyork.us/api/geospatial/cpf4-rkhq?method=export&type=GeoJSON)
2. Save as `neighbourhoods.geojson` in the project root

### 4. Run the Notebook

```bash
jupyter notebook airbnb_predictor.ipynb
```

Use **Kernel → Restart & Run All**.

> Random Forest hyperparameter search may take **1–3 minutes** depending on your machine.

## Methodology Highlights

| Step | Approach |
|------|----------|
| Outliers | Keep nightly price between **$10 and $2,000** |
| Missing data | Impute bedrooms/bathrooms by room type; superhost `unknown`; review median for unrated listings |
| Baseline | Train-set median log price by neighborhood |
| Linear model | **Ridge** (`alpha=10`) instead of unregularized OLS |
| Random Forest | `RandomizedSearchCV` on training data (12 candidates, 3-fold CV) |
| Evaluation | R² on log price; **RMSE and MAE in dollars**; 5-fold CV on **train set only** |

## Limitations

- **Snapshot data** — not a forecasting model; reflects one Inside Airbnb scrape.
- **Imputation bias** — review scores for listings with zero reviews use a global median.
- **Association, not causation** — feature importance does not imply changing a feature will change price.
- **Price cap** — listings above $2,000/night are excluded.
